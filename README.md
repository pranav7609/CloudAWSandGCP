# CloudAWSandGCP
Invoices arrive by email or web upload into S3. EventBridge routes the event, Step Functions orchestrates Textract + Bedrock Nova extraction to DynamoDB, and low-confidence cases pause the workflow for human approval via a WaitForTaskToken callback. Built with Java 21 Lambda and a React dashboard.

Invoice Processing System is a fully serverless, AI-assisted invoice approval pipeline built on AWS. Vendors email PDF invoices to an SES-inbound address or staff upload them through a React web app; either way the file lands in S3, an EventBridge rule routes the ObjectCreated event, and a Step Functions state machine takes over orchestration. AWS Textract's AnalyzeExpense extracts the fields with per-field confidence scores, Amazon Bedrock (Nova-Lite) validates them and assigns a risk level, and the result is persisted to DynamoDB alongside an immutable audit record in S3. Clean invoices are auto-approved. Anything uncertain, incomplete, or duplicated is escalated to a human — and that's where the interesting part is. The state machine doesn't poll, and it doesn't time out waiting. It uses a WaitForTaskToken callback to suspend the execution entirely, embeds the task token in a one-click approval email, and resumes exactly where it left off when the reviewer clicks Approve or Reject, up to 72 hours later. Because every transition lives in Step Functions with its exact input and output, any decision in the audit trail can be replayed and explained.
